# For My Beautiful Wife ❤️

A romantic, mobile-friendly slideshow website made with your uploaded photo and video.

## Preview
Open `index.html` in a browser.

## Publish free with GitHub Pages
1. Sign in to GitHub and create a new **Public** repository (for example, `for-my-wife`).
2. Upload `index.html` and the entire `assets` folder. Keep the filenames and folder structure unchanged.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then Save.
6. Wait for GitHub to publish the site. The Pages URL will appear in that section.

Keep the repository public if you are using the free GitHub Pages plan. Anyone with the link may be able to view the photos and video, so do not publish it publicly if you want those memories kept private.
